Les risques réels d'un faux QR code :

  • 🎣 Phishing : vol de données personnelles
  • 📷 Captation vidéo : images compromettantes
  • 💰 Fraude : paiement vers un faux site
  • 🦠 Malware : installation de logiciels malveillants
  • 🔓 Vol d'identifiants : comptes bancaires, réseaux sociaux

Comment se protéger :

  • 🔍 Vérifiez toujours l'URL après avoir scanné un QR code
  • 🚫 Ne scannez pas un QR code inconnu ou mal placé
  • 📖 Lisez les conditions avant de cocher « j'accepte »
  • 🔒 Refusez les permissions non justifiées
  • 🛡️ Utilisez un scanner de QR code sécurisé
